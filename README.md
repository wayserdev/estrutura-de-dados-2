# Atividade Prática - Operações de BST em Go

Disciplina: Estrutura de Dados 2 - Quinto Período

Esta atividade contém as implementações solicitadas, separadas por exercício:

- `01-criar-e-inserir-bst`: criação da árvore e inserção;
- `02-busca-bst`: busca recursiva e iterativa;
- `03-percursos-bst`: pré-ordem, em ordem, pós-ordem e largura;
- `04-consultas-bst`: altura, contagem, folhas, mínimo e máximo;
- `05-remover-bst`: remoção nos casos folha, um filho e dois filhos.

Para executar um exercício, entre na pasta correspondente e utilize:

```bash
go run main.go
```

Branch solicitada para a entrega: `atividade-bst`.
